# SWORT Neon Studio

Build a modern, fully responsive dark-neon portfolio and video editor website for 'SWORT' meticulously mirroring the provided layout screenshot.

Key sections and aesthetic:
- Theme: Deep dark background (#07030D), neon violet/purple glows and gradients, glassmorphism card styling with subtle purple borders.
- Navigation: Minimal fixed header with 'SWORT' logo, navigation links (Home, About, Services, Work, Contact), and a gradient 'Hire Me' CTA.
- Hero section: Bold 'HELLO MOTION' headline with an embedded circular glowing orb/graphic, arched portrait frame with glowing purple aura, floating badges, '12+' metric, and a partner/tool logo marquee directly underneath.
- Skills section: 'MY MASTERING VIDEO EDITING SKILLS' grid with glassmorphic cards for After Effects, Premiere Pro, DaVinci Resolve, Cinema 4D, etc.
- About section: Creator portrait alongside 'PASSIONATE DIGITAL MARKETER FOCUSED ON DRIVING RESULTS', with stats counters (30+, 100+, 300+).
- Services section: 'HERE'S HOW I CAN HELP!' with 3 feature cards (Web Development, UI/UX Design, Content Writing/Editing) and interactive hover effects.
- Recent Work: 'RECENT WORK FOR MY CLIENTS' portfolio showcase grid with mockup cards, category tags, and clean preview states.
- Slanted ribbon marquee ribbons with glowing text.
- Experience & Achievements: 'MY BACKGROUND AND ACHIEVEMENTS' chronological milestone cards.
- Testimonials: 'LET'S HEAR FROM DEAR CLIENTS' quote card layout with client details and ratings.
- Blog section: 'READ MY RECENT BLOG' 3-card grid with image thumbnails, metadata, and titles.
- Footer: Vibrant purple nebula glow banner with brand blurb, sitemap links, and newsletter subscription form.
