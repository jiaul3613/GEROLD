# SWORT Dark-Neon Portfolio

## What will be built
- Replace the blank homepage with a polished, responsive SWORT portfolio inspired by the supplied reference.
- Create a fixed minimal header, oversized “HELLO MOTION” opening, glowing orb, arched creator portrait, floating badges, 12+ metric, and moving tool strip.
- Add the requested skill, about, services, recent work, milestones, testimonial, blog, and luminous footer sections in the same long-form cinematic order.
- Keep all visible interactions functional: navigation, mobile menu, project links, service states, newsletter field, and primary contact actions.

## Visual direction
- Deep `#07030D` foundation with ultraviolet and orchid light, fine purple borders, restrained glass surfaces, and cinematic glow.
- Instrument Serif for expressive editorial headings and Work Sans for utility and body copy.
- Full-width scene changes, oversized typography, asymmetrical portrait framing, restrained scroll reveals, card lifts, and a continuous marquee.
- Use original generated portrait, project, and article imagery matching the purple-lit editing-studio aesthetic; the uploaded screenshot remains reference-only.

## Responsive behavior
- Preserve the cinematic hierarchy on wide screens while stacking portraits, cards, metrics, and footer content cleanly on phones.
- Use a compact mobile navigation and stable grids so labels, counters, and controls remain readable without overlap.
- Respect reduced-motion preferences.

## Technical details
- Implement the homepage in the existing TanStack Start route and extend the existing Tailwind v4 token system.
- Add app-specific metadata for SWORT and load the selected web fonts through the document head.
- Generate and import optimized local visual assets for the portrait and portfolio imagery.
- Validate the finished page in the live preview at desktop and mobile widths, including layout, links, console state, and image loading.
